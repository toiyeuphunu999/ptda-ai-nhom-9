# Wireframes

## Phạm vi

Wireframe giai đoạn này mô tả bố cục các nhóm màn hình chính; bản UI thật nằm trong `app/Views/` và đã được kiểm tra responsive.

## Shop

Wireframe trực quan: [`shop-overview.svg`](shop-overview.svg).

```text
Header: logo | điều hướng | tìm kiếm | giỏ hàng | tài khoản
Trang chủ: giới thiệu ngắn → danh mục → lưới sách
Danh sách: breadcrumb → tiêu đề → lưới Book Card
Chi tiết: breadcrumb → bìa sách | thông tin và giá
Form: tiêu đề → trường nhập → nút thao tác và trạng thái
Footer: thương hiệu → hỗ trợ → thông tin website
```

## Admin

Wireframe trực quan: [`admin-overview.svg`](admin-overview.svg).

```text
Sidebar: tổng quan / sách / danh mục / đơn hàng / khách hàng
Header: cấp khu vực → tiêu đề → thông tin vận hành
Nội dung: thẻ tổng quan, bảng dữ liệu hoặc empty state
```

Các form nghiệp vụ chính đã nối với backend; form liên hệ hiện chưa gửi dữ liệu. Bản vẽ hình ảnh chính thức được cung cấp bằng SVG trong thư mục này.
