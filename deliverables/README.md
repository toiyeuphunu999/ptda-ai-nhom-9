# Bộ hồ sơ và gói nộp

Các file `docs/*-source.md` là nguồn nội dung của báo cáo và slide đã xuất bằng Word/PowerPoint.

- `bookstore-web212-source-final-v17.zip`: mã nguồn phát hành mới nhất, loại trừ `.env` và dữ liệu runtime.
- `bookstore-web212-sql.zip`: schema, seed và hướng dẫn database.
- `../docs/report-source.md`: nguồn báo cáo.
- `../docs/slides-source.md`: nguồn slide.
- `../docs/submission-status.md`: checklist trạng thái nộp.

Live URL và tài khoản Admin production được ghi trong `docs/deployment.md`. Mật khẩu không nằm trong source package và được bàn giao riêng.
